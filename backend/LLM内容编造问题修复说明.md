# LLM内容编造问题修复说明

## 问题描述

1. **LLM编造内容**：当OCR识别失败或文本为空时，LLM会返回示例内容，如"由于您未提供具体的合同文本，我将按照要求的格式展示一个示例输出结构"
2. **前端显示不当**："待填写"、"请手动填写"等字样出现在合同详情页面，用户体验不佳

## 根本原因

### 问题1：LLM收到空文本仍然返回内容
- OCR识别失败时，提取的文本为空或无效
- LLM服务没有检查文本有效性就直接调用API
- LLM被要求"按格式输出"，所以编造了示例内容

### 问题2：默认值设置不当
- 后端在OCR失败时返回"待识别 - 请手动填写"
- 返回"甲方：待填写"、"乙方：待填写"等默认值
- 前端虽然过滤了部分，但仍有遗漏

## 解决方案

### 1. LLM服务增加文本有效性检查

**文件**: `backend/app/services/llm_service.py` - `extract_full_summary`方法

**改进**:
```python
def extract_full_summary(self, text: str) -> str:
    # 检查文本是否有效
    if not text or len(text.strip()) < 100:
        print("文本为空或太短，跳过LLM提取")
        return ""
    
    # 检查文本是否包含基本的合同关键词
    has_contract_keywords = any(kw in text for kw in [
        "合同", "协议", "甲方", "乙方", "服务", "产品", "付款", "金额"
    ])
    if not has_contract_keywords:
        print("文本不包含合同关键词，可能是OCR识别失败")
        return ""
```

**效果**:
- 文本少于100字符：直接返回空，不调用LLM
- 文本不包含合同关键词：直接返回空，不调用LLM
- 避免LLM收到无效文本

### 2. LLM提示词增加严格规则

**改进**:
```markdown
## 重要规则
**严禁编造内容**：
- 如果合同文本为空、无效或无法识别，请直接返回"无法识别合同内容"
- 只提取文本中实际存在的信息，不要添加任何示例、模板或虚构内容
- 如果某个部分在文本中不存在，请明确说明"未找到相关内容"
- 绝对不要返回"由于您未提供具体的合同文本"这类提示语
```

**效果**:
- 明确禁止LLM编造内容
- 要求LLM在找不到信息时明确说明
- 禁止返回提示性语句

### 3. LLM响应结果验证

**改进**:
```python
# 检查LLM是否返回了无效内容
invalid_phrases = [
    "由于您未提供",
    "示例输出结构",
    "当您提供实际合同",
    "虚构数据",
    "示例为虚构",
    "无法识别合同内容"
]
if any(phrase in result_text for phrase in invalid_phrases):
    print("LLM返回无效内容，跳过")
    return ""
```

**效果**:
- 检测LLM返回的无效内容
- 自动过滤掉编造的示例
- 确保只保存真实提取的内容

### 4. 修改OCR失败时的默认值

**文件**: `backend/app/services/contract_parser.py`

**改进**:
```python
# 旧值
"title": "待识别 - 请手动填写",

# 新值
```

**效果**:
- 标题显示"未识别"而不是"待识别 - 请手动填写"
- 签约方为空数组，前端显示"未识别"
- 日期为None，前端显示"未识别"

### 5. 前端过滤无效值

**文件**: `frontend/src/pages/ContractDetail.tsx`

**改进**:
```typescript
// 过滤掉空值、null、待填写、未识别等无效值
partyList = partyList.filter(p => {
  const str = String(p).trim()
  return str && 
         str !== 'null' && 
         str !== '待填写' && 
         str !== 'undefined' && 
         str !== '未识别'
})

// 如果所有签约方都为空，显示"未识别"
{!partyA && !partyB && !partyC && other.length === 0 && 
  <p className="font-medium text-muted-foreground">未识别</p>
}
```

**效果**:
- 自动过滤所有无效值
- 空值统一显示为"未识别"
- 用户体验更好

1. **重新解析**：对于已上传的合同，如果包含编造的内容，需要点击"重新解析"按钮
