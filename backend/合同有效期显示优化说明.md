# 合同有效期显示优化说明

## 问题描述

用户反馈：合同23（腾讯云服务协议）中没有明确的合同有效期，但系统显示了默认日期`2026-03-01 ~ 2026-03-01`，应该显示"未识别"。

## 问题原因

1. **历史数据问题**：合同23是旧数据，数据库中存储了错误的日期值（`start_date: 2026-03-01`, `end_date: 2026-03-01`）
2. **LLM返回None未正确处理**：当LLM识别不到有效期时返回`None`（Python对象），但重新解析逻辑没有正确处理这种情况，导致旧的错误日期没有被清空

## 解决方案

### 1. 修复重新解析逻辑

修改`backend/app/routers/contracts.py`中的`_async_reparse_process`函数，正确处理LLM返回`None`的情况：

```python
# 服务期限开始日期
if llm_result.get("服务期限开始日期") and llm_result.get("服务期限开始日期") != "null":
    date_str = llm_result["服务期限开始日期"]
    for fmt in ["%Y-%m-%d", "%Y-%m", "%Y/%m/%d", "%Y/%m"]:
        try:
            contract.start_date = datetime.strptime(date_str, fmt)
            break
        except:
            continue
elif "服务期限开始日期" in llm_result and (llm_result["服务期限开始日期"] is None or llm_result["服务期限开始日期"] == "null"):
    # LLM明确返回None或"null"，清空开始日期
    contract.start_date = None
    print(f"[异步重解析] 清空start_date（LLM返回None）")
elif extracted.get("start_date"):
    date_str = extracted["start_date"]
    for fmt in ["%Y-%m-%d", "%Y-%m", "%Y/%m/%d", "%Y/%m"]:
        try:
            contract.start_date = datetime.strptime(date_str, fmt)
            break
        except:
            continue

# 服务期限结束日期（同样的逻辑）
```

关键点：
- 检查`"服务期限开始日期" in llm_result`确保字段存在
- 检查`llm_result["服务期限开始日期"] is None`处理Python的None对象
- 检查`llm_result["服务期限开始日期"] == "null"`处理字符串"null"
- 当LLM返回None时，主动设置`contract.start_date = None`清空旧数据

### 2. 前端显示逻辑

前端已经正确实现了显示逻辑（`frontend/src/pages/ContractDetail.tsx`）：

```typescript
<p className="font-medium">
  {contract.startDate && contract.endDate 
    ? `${formatDate(contract.startDate)} ~ ${formatDate(contract.endDate)}`
    : contract.startDate 
      ? `${formatDate(contract.startDate)} ~ 未识别`
      : contract.endDate
        ? `未识别 ~ ${formatDate(contract.endDate)}`
        : '未识别'}
</p>
```

显示规则：
- 两个日期都有：显示完整日期范围
- 只有开始日期：显示"开始日期 ~ 未识别"
- 只有结束日期：显示"未识别 ~ 结束日期"
- 两个日期都没有：显示"未识别"

## 注意事项

1. **LLM返回值类型**：LLM可能返回Python的`None`对象或字符串`"null"`，需要同时处理两种情况
2. **历史数据清理**：对于已有的错误数据，需要通过重新解析来清空
3. **OCR识别**：如果OCR也没有识别到日期，`_extract_date`方法会返回`None`，这是正确的行为
4. **框架协议**：像腾讯云服务协议这样的框架协议通常没有明确的有效期，显示"未识别"是合理的
