# 重新解析功能修复说明

## 问题描述

用户反馈：
1. 重新解析合同23（腾讯云服务协议）后，甲方、乙方、合同名称等基本信息没有更新
2. AI解析一直进行中，未结束
3. 重新解析后还是无法识别

## 问题原因

1. **后台线程被中断**：使用`daemon=True`的线程在uvicorn reload时会被强制终止
2. **OCR重复调用导致失败**：每次重新解析都调用OCR API，触发百度OCR的QPS限制，导致返回空文本
3. **raw_text未保存**：测试脚本只更新了summary，没有保存raw_text到数据库

## 解决方案

### 1. 优化重新解析逻辑

修改`_async_reparse_process`函数，优先使用数据库中已有的`raw_text`，避免重复OCR：

```python
# 优先使用已有的raw_text，避免重复OCR（节省API调用和时间）
raw_text = contract.raw_text

if raw_text and len(raw_text) > 100:
    print(f"[异步重解析] 使用已有OCR文本，长度: {len(raw_text)}")
    # 从已有文本中提取基本信息
    extracted = {
        "contract_number": contract.contract_number,
        "title": contract.title,
        "parties": json.loads(contract.parties) if contract.parties else [],
        # ...
    }
else:
    # 如果没有raw_text，才重新OCR
    print(f"[异步重解析] 没有已有OCR文本，重新OCR识别...")
    parse_result = contract_parser.parse_contract(file_path_str, "")
    # ...
```

### 2. 增强错误处理和日志

添加详细的日志输出，便于排查问题：

```python
print(f"[异步重解析] 开始解析合同 {contract_id}，文件路径: {file_path_str}")
print(f"[异步重解析] 使用已有OCR文本，长度: {len(raw_text)}")
print(f"[异步重解析] LLM解析结果: {llm_result}")
print(f"[异步重解析] 更新甲乙方: {parties_list}")
print(f"[异步重解析] 更新合同名称: {contract.title}")
print(f"[异步重解析] 合同 {contract_id} 重新解析完成")
```

### 3. 支持生产模式运行

修改`run.py`，支持`--no-reload`参数，在生产环境禁用自动重载：

```python
# 检查是否有--no-reload参数
reload = "--no-reload" not in sys.argv

if not reload:
    print("运行模式: 生产模式（禁用自动重载）")
else:
    print("运行模式: 开发模式（启用自动重载）")

uvicorn.run(
    "app.main:app",
    host="0.0.0.0",
    port=8000,
    reload=reload
)
```

### 4. 修复测试脚本

更新`reparse_contract_23.py`，确保保存`raw_text`到数据库：

```python
# 更新数据库（包括raw_text）
contract.summary = summary
contract.raw_text = text  # 保存OCR文本
db.commit()
print("\n✓ 数据库已更新（包括raw_text）")
```

## 使用说明

### 开发模式（默认）

```bash
python run.py
```

- 启用自动重载，代码修改后自动重启
- 后台线程可能被中断，适合开发调试

### 生产模式

```bash
python run.py --no-reload
```

- 禁用自动重载，后台线程不会被中断
- 适合生产环境或需要完整执行后台任务的场景

## 注意事项

1. **OCR API限制**：百度OCR有QPS限制，频繁调用可能失败。重新解析优先使用已有的`raw_text`
2. **后台任务**：在开发模式下，代码修改会触发reload，可能中断正在执行的后台任务
3. **数据库更新**：重新解析会更新合同的所有字段，包括甲方、乙方、合同名称、摘要等
