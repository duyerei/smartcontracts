# 布局优化说明 - AI助手空间预留

## 问题描述

AI助手展开时（400px宽度）会遮挡主内容区域的内容，影响用户体验。

## 解决方案

在主内容区域右侧预留400px空间，确保AI助手展开时不会遮挡任何内容。

## 实现方式

### 1. Layout组件修改

```tsx
<main className="flex-1 overflow-auto bg-muted/30 p-6 pr-[416px]">
  {/* pr-[416px] = 400px(AI助手宽度) + 16px(padding) */}
  <Outlet />
</main>
```

**说明**：
- `pr-[416px]`：右侧padding为416px
- 计算方式：400px（AI助手宽度）+ 16px（额外间距）
- 确保内容不会被AI助手遮挡

### 2. 视觉提示

在AI助手收起时，显示一个半透明的蓝色区域，提示用户这里是AI助手的展开空间：

```tsx
{/* 右侧留白区域提示（半透明） */}
<div className="fixed right-0 top-0 w-[400px] h-screen bg-blue-50/30 pointer-events-none border-l border-blue-100/50" />
```

**特点**：
- 半透明蓝色背景（bg-blue-50/30）
- 左侧边框（border-l border-blue-100/50）
- 不可交互（pointer-events-none）
- 全屏高度（h-screen）

## 布局结构

```
┌─────────┬──────────────────────────────────┬────────────┐
│         │                                  │            │
│ Sidebar │     主内容区                      │  AI助手    │
│         │     (右侧预留416px)               │  (400px)   │
│ 240px   │                                  │            │
│         │     ┌──────────────────────┐     │            │
│         │     │                      │     │            │
│         │     │   实际内容区域        │     │  收起时：   │
│         │     │                      │     │  半透明    │
│         │     │   不会被遮挡          │     │  提示区域   │
│         │     │                      │     │            │
│         │     └──────────────────────┘     │  展开时：   │
│         │                                  │  完整面板   │
│         │                                  │            │
└─────────┴──────────────────────────────────┴────────────┘
```

## 空间计算

### 总宽度分配
假设屏幕宽度为1920px：

1. **Sidebar**：240px（固定）
2. **主内容区**：1920 - 240 - 400 = 1280px
   - 左padding：24px
   - 右padding：416px（400px AI助手 + 16px间距）
   - 实际内容宽度：1280 - 24 - 416 = 840px
3. **AI助手区域**：400px（固定）

### 响应式考虑

- 小屏幕（<1440px）：内容区域会自动缩小
- 大屏幕（>1920px）：内容区域会自动扩展
- AI助手宽度始终保持400px

## 优势

### 1. 不遮挡内容
- 主内容区域完全可见
- 表格、列表不会被截断
- 操作按钮不会被遮挡

### 2. 视觉清晰
- 半透明提示区域让用户知道右侧是AI助手空间
- 蓝色边框明确区域边界
- 收起时不影响视觉

### 3. 用户体验
- 无需手动调整窗口
- 内容自动适配
- 流畅的展开/收起动画

## 对比

### 修改前
```
主内容区：占满整个宽度
AI助手：悬浮在内容上方，遮挡右侧400px
问题：内容被遮挡，需要滚动或关闭AI助手才能查看
```

### 修改后
```
主内容区：右侧预留416px空间
AI助手：固定在预留空间内
优势：内容完全可见，AI助手不遮挡任何内容
```

## 注意事项

### 1. 最小屏幕宽度
建议最小屏幕宽度：1280px
- Sidebar：240px
- 主内容区最小：640px
- AI助手：400px

### 2. 移动端适配
在移动端（<768px）可以考虑：
- AI助手改为全屏模态框
- 或者底部抽屉式展开
- 主内容区不预留空间

### 3. 打印样式
打印时应隐藏AI助手和预留空间：
```css
@media print {
  .ai-assistant { display: none; }
  main { padding-right: 1.5rem !important; }
}
```
