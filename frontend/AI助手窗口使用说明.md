# AI助手窗口使用说明

## 功能概述

改造后的AI助手窗口，默认收起显示虚拟形象，展开后支持完整的拖拽和调整大小功能。

## 交互功能

### 1. 收起状态（默认）
- **位置**：固定在页面右下角
- **外观**：AI虚拟形象（圆形头像 + 蓝色渐变背景）
- **动效**：
  - 呼吸光效（持续动画）
  - 鼠标悬停时整体放大110%
  - 挥手动效（手臂摆动）
  - 装饰性星星✨
  - 显示"点击展开对话"提示
- **操作**：点击虚拟形象展开窗口

### 2. 展开状态

#### 移动窗口
- **拖拽区域**：窗口头部（蓝色渐变区域）
- **操作方式**：按住头部拖拽即可移动窗口位置
- **提示**：头部显示"(拖拽移动)"文字，鼠标悬停时颜色加深

#### 调整窗口大小

**左侧边缘**
- **拖拽区域**：窗口左侧整条边缘（宽3px）
- **操作方式**：鼠标移到左侧边缘，光标变为 ↔️，拖拽调整宽度
- **视觉反馈**：悬停时显示蓝色半透明背景

**上方边缘**
- **拖拽区域**：窗口上方整条边缘（高3px）
- **操作方式**：鼠标移到上方边缘，光标变为 ↕️，拖拽调整高度
- **视觉反馈**：悬停时显示蓝色半透明背景

**右下角**
- **拖拽区域**：窗口右下角（5x5px区域，带边框图标）
- **操作方式**：鼠标移到右下角，光标变为 ↘️，同时调整宽度和高度
- **视觉反馈**：悬停时显示蓝色半透明背景，有边框图标提示

#### 关闭窗口
- **操作**：点击头部右上角的 X 按钮
- **效果**：窗口收起，恢复为虚拟形象

### 3. 窗口尺寸限制
- **最小宽度**：360px
- **最小高度**：320px
- **最大宽度**：屏幕宽度的90%
- **最大高度**：屏幕高度的85%
- **默认尺寸**：480px × 560px

## 使用技巧

1. **快速调整宽度**：拖拽左侧边缘
2. **快速调整高度**：拖拽上方边缘
3. **同时调整宽高**：拖拽右下角
4. **移动位置**：拖拽头部
5. **临时收起**：点击X按钮，需要时再点击虚拟形象展开

## 视觉设计

### 收起状态
- 蓝色渐变背景（from-blue-50 via-blue-100 to-blue-200）
- 白色边框（4px）
- 阴影效果（shadow-2xl）
- 圆形头像（蓝色渐变 from-blue-500 to-blue-600）
- 底部标签（渐变蓝色 from-blue-500 to-blue-600）

### 展开状态
- 头部：渐变蓝色（from-blue-500 to-blue-600）
- 内容区：白色背景
- 边框：蓝色半透明（border-primary/20）
- 阴影：shadow-xl

### 拖拽区域反馈
- 悬停时显示蓝色半透明背景（bg-blue-500/20）
- 光标自动变化（cursor-move, cursor-ew-resize, cursor-ns-resize, cursor-se-resize）

## 动画效果

### 挥手动画
```css
@keyframes wave {
  0%, 100% { transform: rotate(0deg); }
  10% { transform: rotate(14deg); }
  20% { transform: rotate(-8deg); }
  30% { transform: rotate(14deg); }
  40% { transform: rotate(-4deg); }
  50% { transform: rotate(10deg); }
  60% { transform: rotate(0deg); }
}
```
- 持续时间：1秒
- 循环：无限
- 触发：鼠标悬停

### 其他动画
- 呼吸光效：animate-pulse
- 悬停缩放：hover:scale-110
- 星星出现：opacity + scale 过渡
- 提示文字：opacity + translateY 过渡

## 技术实现

- React 18 + TypeScript
- Tailwind CSS（动画、渐变、阴影）
- 拖拽：原生 MouseEvent API
- 位置限制：自动计算边界，防止窗口超出屏幕

## 注意事项

1. 窗口位置会自动限制在屏幕范围内
2. 调整大小时会自动限制最小/最大尺寸
3. 拖拽时不会触发其他点击事件
4. 所有动画使用CSS实现，性能优秀
