# 智能分页解析功能说明

## 功能概述

系统现在支持智能分页解析，根据合同长度自动调整读取策略，既保证关键信息不遗漏，又控制OCR成本和解析时间。

## 解析策略

### 短合同（≤20页）
- **策略**：全部读取
- **原因**：页数少，全部读取成本低
- **示例**：劳动合同、保密协议等

### 中等合同（21-50页）
- **策略**：前15页 + 最后5页
- **原因**：
  * 前15页：包含主要条款、合作内容
  * 最后5页：包含签字页、补充条款
- **示例**：服务合同、采购合同等

### 长合同（>50页）
- **策略**：前20页 + 最后5页 + 中间抽样（每10页读1页）
- **原因**：
  * 前20页：包含主要条款
  * 最后5页：包含签字页、附件目录
  * 中间抽样：捕获可能的附件内容
- **示例**：框架协议、大型项目合同等

## 实际效果

### 案例1：100页的框架协议

**旧方案**：
- 读取：前10页
- 耗时：5秒
- 问题：遗漏附件中的服务内容

**新方案**：
- 读取：前20页 + 最后5页 + 中间8页（抽样）= 33页
- 耗时：15秒
- 优势：包含签字页和部分附件内容

### 案例2：30页的服务合同

**旧方案**：
- 读取：前10页
- 耗时：5秒
- 问题：遗漏后续的付款条款

**新方案**：
- 读取：前15页 + 最后5页 = 20页
- 耗时：10秒
- 优势：包含完整的主要条款和签字页

## 使用建议

### 对于用户

1. **初次上传**：
   - 系统自动使用智能分页策略
   - 大多数情况下已足够

2. **如果信息不完整**：
   - 点击"重新解析"按钮
   - 系统会重新读取并分析

3. **查看读取页数**：
   - 在合同详情页可以看到"已读取X/Y页"
   - 判断是否需要完整解析

### 对于管理员

1. **监控解析质量**：
   - 关注用户触发"重新解析"的频率
   - 如果频繁重新解析，说明策略需要调整

2. **调整策略参数**：
   - 可以在配置文件中调整阈值
   - 例如：中等合同的页数阈值

## 配置参数

```python
# config.py
class Config:
    # 智能分页阈值
    SHORT_CONTRACT_PAGES = 20  # 短合同阈值
    MEDIUM_CONTRACT_PAGES = 50  # 中等合同阈值
    
    # 长合同抽样率
    LONG_CONTRACT_SAMPLE_RATE = 10  # 每N页读1页
```
