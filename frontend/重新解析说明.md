# 重新解析功能说明

## 为什么需要重新解析？

对于在系统升级前上传的合同，可能存在以下问题：
1. 缺少签订时间字段（新增字段）
2. 日期识别不准确（旧的提取逻辑）
3. 三方合同的丙方信息未提取

## 如何使用重新解析功能？

1. 打开合同详情页
2. 在"主要合作内容与付款方式"卡片右上角，点击"重新解析"按钮
3. 系统会显示"AI正在智能解析中，请稍候..."
4. 等待几秒钟，页面会自动更新显示新的解析结果

## 重新解析会更新哪些内容？

- 签订时间（新增）
- 服务期限开始日期（优化）
- 服务期限结束日期（优化）
- 签约方信息（包括丙方）
- 合同摘要（使用最新的LLM提取）

## 针对"劳动关系转移协议"的特殊说明

这份合同的日期信息比较特殊：
- **签订时间**：2022年01月12日（合同末尾的签字日期）
- **服务开始日期**：2022年01月01日（"建立劳动关系"的日期）
- **服务结束日期**：可能为空（转移协议通常没有明确的结束日期）

重新解析后，系统会：
1. 正确识别签订时间为 2022-01-12
2. 正确识别服务开始日期为 2022-01-01
3. 如果没有明确的结束日期，该字段将为空，不显示"有效期"

## 日期提取优化

新的日期提取逻辑支持：
1. **签订时间**：
   - 优先匹配"签订"、"签署"、"签约"等关键词
   - 如果没有明确标注，会提取合同末尾的日期（通常是签字日期）

2. **服务开始日期**：
   - 匹配"生效"、"开始"、"起始"、"自"等关键词
   - 特别支持"建立劳动关系"等特殊表述

3. **服务结束日期**：
   - 匹配"结束"、"终止"、"到期"、"至...止"等关键词
   - 如果没有明确的结束日期，返回 null

## 注意事项

- 重新解析不会删除或覆盖手动编辑的内容
- 如果LLM解析失败，会保留原有的基础解析结果
- 重新解析是异步执行的，通常需要5-10秒完成
- 解析完成后页面会自动刷新显示最新内容
