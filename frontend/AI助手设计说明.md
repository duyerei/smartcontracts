# AI助手窗口 - 现代化设计

## 设计理念

采用右侧固定面板的方式，不遮挡主内容区域，提供更好的用户体验。

## 主要特性

### 1. 收起状态（默认）

**位置**：固定在页面右侧中间
**外观**：
- 蓝色渐变背景（from-blue-500 to-blue-600）
- 圆形AI头像（白色背景）
- 竖排文字"AI助手"
- 小箭头提示（◀）
- 呼吸光效动画

**交互**：
- 鼠标悬停时按钮向左扩展
- 头像放大效果
- 点击展开右侧面板

### 2. 展开状态

**布局**：
- 固定在页面右侧
- 宽度：400px
- 高度：100vh（全屏高度）
- 不遮挡主内容区域

**结构**：
```
┌─────────────────────────────┐
│  头部（蓝色渐变）              │
│  - AI头像 + 标题              │
│  - 关闭按钮                   │
├─────────────────────────────┤
│  快捷问题（首次显示）          │
│  - 查看所有合同               │
│  - 即将到期的合同             │
│  - 查看合同16                │
│  - 帮我分析合同风险           │
├─────────────────────────────┤
│  聊天内容区（可滚动）          │
│  - 用户消息（右侧蓝色）        │
│  - AI消息（左侧白色）          │
│  - 合同数据卡片               │
├─────────────────────────────┤
│  输入区                       │
│  - 输入框（圆角）             │
│  - 发送按钮（圆形）           │
│  - 免责声明                   │
└─────────────────────────────┘
```

## UI设计细节

### 颜色方案
- **主色调**：蓝色（#3B82F6 - #2563EB）
- **背景色**：
  - 聊天区：灰色（#F9FAFB）
  - 消息气泡：白色/蓝色
- **文字色**：
  - 主文字：#1F2937
  - 次要文字：#6B7280
  - 提示文字：#9CA3AF

### 圆角设计
- 消息气泡：rounded-2xl（16px）
- 输入框：rounded-full（完全圆角）
- 按钮：rounded-full
- 卡片：rounded-xl（12px）

### 阴影效果
- 面板：shadow-2xl
- 消息气泡：shadow-sm
- 卡片悬停：shadow-md

### 动画效果
1. **展开动画**：slide-in-from-right（从右侧滑入）
2. **呼吸光效**：animate-pulse
3. **加载动画**：三个圆点跳动
4. **悬停效果**：scale、shadow变化

## 功能特性

### 快捷问题
- 首次打开时显示4个推荐问题
- 点击后自动填充并发送
- 发送消息后隐藏

### 消息展示
- **用户消息**：右对齐，蓝色背景，右下角尖角
- **AI消息**：左对齐，白色背景，左下角尖角
- **合同卡片**：白色背景，圆角边框，悬停阴影

### 合同数据卡片
- 标题（可点击跳转）
- 状态标签（蓝色圆角）
- 详细信息（编号、类型、部门、金额、到期日）
- 悬停效果（阴影加深）

### 输入交互
- Enter键发送消息
- Shift+Enter换行
- 发送按钮（圆形，蓝色）
- 禁用状态（加载中或输入为空）

## 响应式设计

### 固定宽度
- 展开宽度：400px
- 不随屏幕大小变化
- 主内容区自动调整

### 滚动处理
- 聊天区域独立滚动
- 输入区固定在底部
- 头部固定在顶部
