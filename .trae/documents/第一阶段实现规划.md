# AI智能合同管理系统 - 第一阶段实现规划

## 一、阶段目标

**MVP（最小可行产品）**：完成合同管理核心功能，实现PDF上传、AI解析、基本查询

## 二、技术方案调整

| 模块 | 原方案 | 本地开发方案 |
|------|--------|-------------|
| 对象存储 | 阿里云OSS | 本地文件系统 (./storage) |
| 数据库 | PostgreSQL | SQLite (开发阶段) |
| 向量库 | Milvus | 轻量方案（可后续集成） |
| 部署 | Docker | 直接运行 (Python) |
